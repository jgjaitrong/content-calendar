# Content Calendar

ปฏิทินคอนเทนต์และตารางกิจกรรมสำหรับทีม (Single-file HTML — เปิดในเบราว์เซอร์ได้ทันที)

## เข้าดูออนไลน์
เมื่อเปิด GitHub Pages แล้ว จะเข้าดูได้ที่:
```
https://<your-username>.github.io/<repo-name>/
```

## เปิดในเครื่อง
ดับเบิ้ลคลิก `index.html` ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม

## แก้ไข
ไฟล์ทั้งหมด (HTML + CSS + JS) รวมอยู่ในไฟล์เดียว: `index.html`
